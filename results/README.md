# Results

`results/full/` holds the outputs of the main experiment (`make train && make evaluate`,
configuration in `configs/full.yaml`, five seeds). Everything in it was produced by the code in this
repository from the UCI Adult files; nothing was edited by hand.

| File | Content |
|---|---|
| `summary.md` | generated tables (mean ± standard deviation across seeds, paired differences, graph diagnostics) |
| `metrics.csv` | every metric for every (seed, method): the raw material of the tables |
| `graph_diagnostics.csv` | edge homophily, adjusted homophily, per-column label agreement, hubness and build time of every graph, per seed |
| `training_logs.csv` | training and validation loss every `eval_every` steps, per seed and method |
| `run_info.json` | data size after cleaning and the versions of Python, torch, PyG and the other libraries used |
| `config.yaml` | copy of the configuration that produced the run |
| `figures/` | PNG figures drawn from the tables above (and, for the t-SNE panel, from the saved embeddings) |

The numeric values in these files are generated by the evaluation code. The embeddings themselves
(`runs/`, about 2.5 MB per method and seed) are not committed; `make train`
recreates them, and the training stage skips files that already exist.

`results/quick/` (smoke-test run, not tracked) is written by `make quick`. Its numbers come from a
6,000-row subsample, one seed and 300 training steps and are too noisy to interpret.
